# NQ Phone (Android)

تطبيق تليفون للسنترال بيفضل متصل والموبايل مقفول، ولما تيجي مكالمة بينوّر الشاشة ويرن.

## بناء الـ APK من غير أي برامج (GitHub)
1. اعمل Repository جديد (Private) على github.com وارفع فيه كل ملفات الفولدر ده.
2. افتح تبويب **Actions** ← هتلاقي "Build APK" شغّال لوحده (أو اضغط **Run workflow**).
3. لما يخلص (حوالي 5 دقايق) افتح التشغيل ← تحت **Artifacts** نزّل **NQPhone-apk** ← فك الضغط ← `app-debug.apk`.

## أو من Android Studio
افتح الفولدر ← Build ← Build APK(s).

## على موبايل الموظف
1. ثبّت الـ APK (اسمح بـ "تثبيت من مصادر غير معروفة").
2. افتح التطبيق ← وافق على: المايك، الإشعارات، "تجاهل تحسين البطارية"، و"الإشعارات بملء الشاشة".
3. اكتب رقم التحويلة والباسورد مرة واحدة، والتطبيق هيفتكرهم.
4. في سامسونج: Settings ← Battery ← Background usage limits ← Never sleeping apps ← ضيف **NQ Phone**.
5. متقفلش التطبيق من قايمة التطبيقات المفتوحة (Swipe). زرار الرجوع بيصغّره بس.

إعدادات السيرفر في `app/src/main/assets/phone.html` (CONFIG في أول الـ script).
